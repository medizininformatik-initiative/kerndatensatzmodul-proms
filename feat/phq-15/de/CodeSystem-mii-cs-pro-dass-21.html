CodeSystem: MII CS PRO DASS-21 Response Scale and Item Codes (Experimentell)

Offizielle URL: https://www.medizininformatik-initiative.de/fhir/ext/modul-pro/CodeSystem/mii-cs-pro-dass-21 Version: 2026.4.1
Active Stand: 2026-06-29 Maschinenlesbarer Name: MII_CS_PRO_DASS_21

CodeSystem for the Depression Anxiety Stress Scales - Short Form (DASS-21) with answer codes, item codes, and multilingual support (English primary, German translations from Nilges & Essau 2015)

Dieses CodeSystem wird in der Definition der folgenden ValueSets referenziert:

  • MII_VS_PRO_DASS_21_Answer_List

This case-sensitive code system https://www.medizininformatik-initiative.de/fhir/ext/modul-pro/CodeSystem/mii-cs-pro-dass-21 defines the following codes:
