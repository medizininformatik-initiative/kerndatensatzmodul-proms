## NTx Adherence Instruments (metadata-only)

### Clinical Context

The PCOR-MII use case **kidney transplantation (NTx)** collects three instruments on **medication adherence** and **symptom burden**: **BAASIS** (self-report on taking immunosuppressive medication), **ABQ** (adherence barriers) and **MTSOSD-R59** (symptom burden with distress rating). BAASIS and ABQ are linked: the ABQ is only collected when there is an indication of non-adherence.

> **Important:** All three instruments are **metadata-only (Tier B)**. This module provides structure, linkIds, types, value ranges and conditions, but **no item wording and no answer labels**. Item texts are neutral labels, and answer levels are neutrally named "Stufe n" (level n). The full versions are distributed exclusively through the access-restricted Form Server, never in the package.

### BAASIS

**Canonical URL:** `https://www.medizininformatik-initiative.de/fhir/ext/modul-pro/Questionnaire/mii-qst-pro-baasis`

**Structure:** 10 variables. Yes/no items via the shared RuleSet `YesNoAnswerOptions` (SNOMED CT). Frequency sub-questions on a neutral 5-level scale (`mii-cs-pro-baasis-frequency`, level 1–5, weights 1–5). Items 4 and 5 refer to a one-year recall period.

| | | |
| :--- | :--- | :--- |
| `baasis-q1a` | yes/no | – |
| `baasis-q1a-freq` | level 1–5 | item 1A = yes |
| `baasis-q1b` | yes/no | item 1A = yes |
| `baasis-q1b-freq` | level 1–5 | item 1B = yes |
| `baasis-q2` | yes/no | – |
| `baasis-q2-freq` | level 1–5 | item 2 = yes |
| `baasis-q3` | yes/no | – |
| `baasis-q4` | yes/no | – |
| `baasis-q5` | yes/no | – |
| `baasis-q5a` | yes/no | item 5 = yes |

**Scoring:** There is no sum score. Classification as non-adherent is dichotomous: a "yes" on any of items 1A, 2, 3 or 4. This is **documented only**, not shipped as an executable expression.

### ABQ

**Canonical URL:** `https://www.medizininformatik-initiative.de/fhir/ext/modul-pro/Questionnaire/mii-qst-pro-abq`

**Structure:** 16 items (`abq-q01`…`abq-q16`) on a neutral 4-level scale (`mii-cs-pro-abq-answers`, level 1–4, weights 1–4). The score item `abq-score-total` computes the sum via a FHIRPath variable.

**Condition (cross-questionnaire):** According to the Item Level Dictionary, the ABQ is only collected when BAASIS 1A, 2, 3 or 4 is answered "yes". This condition is **not modelled as `enableWhen`** but documented as a comment and must be controlled by the calling process. For the first ABQ entry the dictionary names only BAASIS 1A; presumably an inconsistency to be clarified.

**Scoring:** Sum of the 16 items, range **16–64**, higher values mean more adherence barriers. ObservationDefinition `mii-obsdef-pro-score-abq` (catalogue code `abq-total`). No cut-offs are shipped.

> **Open:** Whether the weights 1–4, in the order of the answer levels, express barrier strength in the expected direction has not been verified against the original instrument and must be checked before productive use.

### MTSOSD-R59

**Canonical URL:** `https://www.medizininformatik-initiative.de/fhir/ext/modul-pro/Questionnaire/mii-qst-pro-mtsosd-r59`

**Structure:** 59 symptoms plus 3 free-text symptoms, symptom 27 sex-specific (62 symptom entries in total). Two items per symptom: **occurrence** (neutral 5-level scale, `mii-cs-pro-mtsosd-r59-occurrence`, level 0–4, weights 0–4) and **distress** (integer, suffix `-distress`).

| | | |
| :--- | :--- | :--- |
| `mtsosd-r59-q01`…`q59` | level 0–4 | – |
| `mtsosd-r59-q27-male`,`-q27-female` | level 0–4 | sex (external) |
| `mtsosd-r59-qNN-distress` | integer | occurrence ≠ level 0 |
| `mtsosd-r59-q60`…`q62` | free text | – |
| `mtsosd-r59-q60-distress`…`q62-distress` | integer | free text present |

**Conditions:** Steering symptom 27 by sex is a cross-questionnaire condition and is not modelled as `enableWhen`. The questionnaire is generated by script (`scripts/generate-mtsosd-r59-stub.py`).

> **Open:** The number of levels of the visual distress scale is not documented in the Item Level Dictionary; distress is therefore modelled without minimum and maximum.

**Scoring:** No score is shipped. Sums over occurrence and distress exist in the literature; their definition has not been verified here.
